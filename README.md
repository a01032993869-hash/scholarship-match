# 장학매치

대학생에게 맞는 장학금과 청년 지원사업을 빠르게 찾아 주는 모바일 우선 데모 웹앱입니다.

## 주요 기능

- 카카오 간편 시작 흐름을 반영한 기본 프로필 입력
- 학교·학년·거주지를 기준으로 한 맞춤 공고 화면
- 장학금, 생활비, 주거, 취업 지원 카테고리 필터
- 공고 상세 정보와 찜하기 상태 관리
- D-7, D-3, 마감일 알림 UX 안내

## 실행 방법

별도 설치가 필요 없습니다. `index.html`을 브라우저에서 열면 실행됩니다.

간단한 로컬 서버가 필요하다면 프로젝트 폴더에서 아래 명령을 사용하세요.

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000`으로 접속합니다.

## 파일 구조

```
scholarship-match/

```

## 참고

현재 공고와 카카오 로그인, 푸시 알림, 원본 신청 페이지 연결은 데모 데이터와 UI 흐름으로 구현했습니다. 실서비스 연동 시에는 인증 API, 공고 데이터 API, 푸시 권한 및 실제 신청 URL을 연결하면 됩니다.
